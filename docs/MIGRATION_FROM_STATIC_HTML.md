# Migracion desde HTML estatico

## Eliminado

- HTML duplicado por pagina.
- Navegacion copiada manualmente.
- Selector de idioma basado solo en JavaScript.
- Rutas no SEO.

## Nuevo enfoque

- Astro.
- Layout comun.
- Rutas `/es/`, `/en/`, `/de/`.
- Slugs traducidos con `routeAlternates`.
- Componentes reutilizables.
- Datos centralizados.
