# I18N

## Idiomas

- Espanol: `/es/`
- Ingles: `/en/`
- Aleman: `/de/`

## Slugs traducidos

Ejemplo:

```text
/es/servicios/
/en/services/
/de/leistungen/
```

## Route alternates

Todas las equivalencias estan en:

```text
src/i18n/routes.ts
```

No usar reemplazo simple de `/es/` por `/en/`, porque los slugs son distintos.

## Anadir pagina

1. Anadir clave en `RouteKey`.
2. Anadir entrada en `routeAlternates`.
3. Anadir contenido en `pageContent` para `es`, `en` y `de`.
4. Ejecutar `npm run check` y `npm run build`.
